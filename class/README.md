# Class List (클래스 목록)

이 폴더는 B-Square 플랫폼에서 제공하는 모든 클래스를 탐색하고 검색할 수 있는 클래스 목록 페이지를 포함하고 있습니다.

## 📁 주요 파일 구성
- `class_list.html`: 클래스 목록의 메인 구조. 카테고리 필터, 정렬 옵션, 검색창 및 클래스 카드 그리드를 포함.
- `class_list.css`: 클래스 목록 페이지 전용 스타일시트. 카드 호버 효과, 필터 바 디자인 등 정의.
- `class_list.js`: 클래스 목록의 핵심 로직. Firebase에서 클래스 데이터를 로드하고, 사용자의 입력(카테고리 선택, 정렬 변경, 검색어 입력)에 따라 동적으로 목록을 필터링 및 렌더링.

## 🛠️ 주요 기능
1. **실시간 클래스 로딩**: Firebase Realtime Database의 `classes` 노드에서 최신 클래스 정보를 가져와 표시합니다.
2. **다중 필터링 및 검색**:
   - **카테고리**: 좌측(또는 상단) 카테고리 메뉴를 통한 분류별 보기.
   - **검색**: 클래스 제목 및 설명을 기반으로 한 실시간 검색 (Debounce 적용).
   - **정렬**: 최신순, 인기순, 가격순(낮은/높은순) 정렬 지원.
3. **반응형 카드 레이아웃**: 기기 화면 크기에 따라 최적화된 그리드 시스템을 제공합니다.
4. **상세 페이지 연결**: 각 클래스 카드를 클릭하면 해당 클래스의 상세 페이지(`class_view/class_view.html?id=...`)로 이동합니다.

## ⚠️ 주의 사항
- 클래스 데이터는 Firebase에서 가져오지만, 수강권 정보 확인 등을 위해 Supabase 초기화도 필요할 수 있습니다.
- `header.js`가 전역적으로 로드되어 상단 헤더와 검색바 로직을 공유합니다.

# Contact (문의하기)

이 폴더는 사용자가 서비스 운영진에게 문의를 남기거나 외부 고객센터(카카오톡 채널 등)로 연결할 수 있는 기능을 포함하고 있습니다.

## 📁 주요 파일 구성
- `contact.html`: 문의하기 페이지의 구조. 카테고리 선택, 이름, 이메일, 제목 및 내용 입력 폼 포함.
- `contact.css`: 문의 페이지 전용 스타일시트. 폼 요소 스타일링 및 관리자용 문의 목록 레이아웃 정의.
- `contact.js`: 문의 페이지의 핵심 로직. 문의 내용 유효성 검사, Firebase 제출, 카카오톡 채널 연결 및 개발자 모드 전용 문의 관리 UI 포함.

## 🛠️ 주요 기능
1. **문의 접수**: 사용자가 작성한 문의 내용을 Firebase Realtime Database의 `inquiries` 노드에 저장합니다.
2. **카카오톡 채널 연동**: Kakao SDK를 사용하여 클릭 시 공식 카카오톡 채널 채팅방으로 즉시 연결합니다.
3. **관리자 모드 (Dev Mode)**: 개발자 모드 활성 시, 페이지 하단에 실시간으로 접수된 문의 목록을 확인하고 상세 내용을 볼 수 있는 관리 섹션이 나타납니다.
4. **실시간 상태 업데이트**: 관리자가 문의를 확인하고 처리하는 과정을 실시간으로 모니터링할 수 있는 기반을 제공합니다.

## ⚠️ 주의 사항
- `contact.js`에서 카카오 채널 ID(`_ScJxon`)가 하드코딩되어 있으므로 채널 변경 시 수정이 필요합니다.
- 문의 제출 시 이메일 형식을 포함한 필수 항목 검증 로직이 포함되어 있습니다.

# Create Class (클래스 개설)

이 폴더는 강사 또는 운영자가 새로운 클래스를 등록하고 개설할 수 있는 단계별 클래스 생성 시스템을 포함하고 있습니다.

## 📁 주요 파일 구성
- `create_class.html`: 클래스 개설을 위한 멀티 스텝(Multi-step) 폼 구조. 기본 정보, 상세 설명, 수강권 설정, 강사 정보 단계 포함.
- `create_class.css`: 클래스 개설 페이지 전용 스타일시트. 진행 단계 인디케이터(Step Indicator), 폼 섹션 애니메이션, 버튼 스타일 등 정의.
- `create_class.js`: 클래스 개설의 핵심 로직. 단계별 유효성 검사, Quill.js 리치 텍스트 에디터 초기화, 이미지 업로드 처리 및 Firebase로의 데이터 최종 제출 담당.

## 🛠️ 주요 기능
1. **단계별 입력 프로세스**: 사용자 경험을 개선하기 위해 긴 폼을 5단계로 나누어 입력받으며, 각 단계 이동 시 필수 항목 입력 여부를 검증합니다.
2. **리치 텍스트 에디터 (Quill.js)**: 클래스 상세 설명을 위해 서식 지정, 이미지 삽입, 링크 연결 등이 가능한 고급 에디터를 제공합니다.
3. **동적 수강권 설정**: 월정액, 기간제 등 다양한 형태의 수강권 옵션을 추가하고 관리할 수 있습니다.
4. **실시간 미리보기 및 보존**: 사용자가 입력한 데이터가 유실되지 않도록 관리하며, 최종 제출 전 검토가 가능합니다.
5. **권한 제어**: 일반 사용자는 로그인이 필요하며, 개발자 모드(`OPERATOR_GHOST`)를 통한 운영자 전용 개설 기능도 지원합니다.

## ⚠️ 주의 사항
- 클래스 데이터는 Firebase Realtime Database의 `classes` 노드에 저장됩니다.
- 이미지 파일 업로드 기능이 포함되어 있으므로, 스토리지 권한 설정 확인이 필요합니다.

# B-Square 프로젝트 고도화 작업 최종 요약

본 문서는 클래스 채널 UI/UX 개선, 수강권/쿠폰 시스템 구현, 친구 기능 및 DM API 안정화 작업을 포함한 전체 변경 사항을 정리합니다.

## 1. 클래스 채널 UI/UX 고도화 ✅
- **헤더 디자인**: 로고 블록 제거 후 클래스 썸네일(아바타) + "클래스명 채팅채널" 텍스트로 깔끔하게 정리.
- **정보 패널**: 
    - Push 방식 레이아웃 및 3px 초박형 스크롤바 적용.
    - 역할별 뱃지(👑 강사, 🎓 서브강사, 수강생) 및 실시간 온라인 상태(Green Dot) 표시.
    - 강사 전용 관리 도구(수강권 발행/사용 통계) 및 수강생 전용 뷰 분리.
- **채팅바**: 수강생 계정에서 모집 카드 생성(달력 아이콘) 권한 제한 및 디자인 최적화.

## 2. 수강권 및 쿠폰 시스템 ✅
- **수강권 발행**: 원데이(1개), 월정액(7개/결제시), 패키지 등 설정에 따른 자동/수동 발행 로직 구현 (`/api/passes/issue`).
- **수강권 통계**: 정보 패널 상단에 "누적 발행 / 사용 수강권" 통계 실시간 연동.
- **쿠폰 관리**: 중복 코드 방지(UNIQUE 제약 조건 처리), 발행 내역 로드 오류 수정, 삭제 기능 연동.

## 3. 친구 network 및 소셜 기능 ✅
- **친구 API (`/api/friends`)**: 요청, 수락, 거절, 삭제, 상태 확인 기능 완비.
- **JOIN Fallback**: DB 스키마 차이로 인한 서버 오류(500) 방지를 위해 `users` 테이블 JOIN 실패 시 자동 Fallback 처리.
- **마이페이지**: '친구' 탭 신규 추가 및 요청 관리 UI 구현.

## 4. 메시징 및 커뮤니티 안정화 ✅
- **DM API (`/api/dm/[[path]]`)**: 
    - `/api/dm/[room_id]/messages` 경로에 대한 Catch-all 라운더 구현.
    - 메시지 전송 필드명 혼용(`content`, `message`, `text`) 자동 정규화 처리.
    - 메시지 수정(PATCH) 및 강사 전용 고정(Pin) 기능 기반 마련.
- **커뮤니티 연동**: 커뮤니티 페이지 내 채팅 목록 및 메시지 영역 API 연동 완료.

## 5. 주요 버그 수정 (Hotfixes) ✅
- **400/500 에러 해결**: 모집 참가자 조회 시 `class_id` 필수 체크 로직 수정 및 DB 컬럼명 불일치(`code` -> `coupon_code`) 해결.
- **데이터 자동 복구**: API 호출 시 관련 테이블(`dm_messages`, `coupons`, `pass_issue_logs` 등)이 없을 경우 자동 생성(`CREATE TABLE IF NOT EXISTS`) 로직 추가.

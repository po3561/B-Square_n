# B-Square 사용자 인증 시스템 프로젝트 분석

이 프로젝트는 **B-Square** 플랫폼의 사용자 인증(로그인, 회원가입, 계정 찾기) 기능을 담당하는 프론트엔드 모듈입니다.

## 🚀 기술 스택
*   **Language:** HTML5, CSS3, JavaScript (Vanilla JS)
*   **Backend Services:**
    *   **Supabase:** 데이터베이스 및 인증 서비스 연동 (v2)
    *   **Firebase:** 인증 및 실시간 데이터베이스 연동 (v9 Compat 버전)
*   **UI/UX:**
    *   반응형 디자인 (Mobile & PC 분리형 스타일시트)
    *   공통 헤더/푸터 동적 삽입 (`header.js`)

## 📁 주요 파일 및 기능

### 1. 로그인 (`login.html`, `auth_1.js`)
*   **기능:** 이메일/아이디 기반 로그인, 아이디 저장(Cookie/LocalStorage), 계정 찾기 및 회원가입 페이지 연결.
*   **특징:** `auth_1.js`를 통해 로그인 로직 및 유효성 검사를 수행합니다.

### 2. 회원가입 (`signup.html`, `auth.js`)
*   **기능:** 단계별 회원가입 프로세스 구현.
    *   **1단계:** 약관 동의 (필수/선택 항목 구분, 모달 상세 보기).
    *   **2단계:** 회원 정보 입력 (아이디 중복 확인, 비밀번호 조합 검사, 이메일/휴대폰 입력).
    *   **3단계:** 가입 완료 안내.
*   **특징:** 사용자 경험을 고려한 단계별 UI(Step Indicator)가 적용되어 있습니다.

### 3. 계정 찾기 (`find_account.html`, `find_account.js`)
*   **기능:** 아이디 찾기 및 비밀번호 재설정 링크 발송.
*   **특징:** 탭 메뉴 형식으로 아이디/비밀번호 찾기 기능을 전환하여 제공합니다.

### 4. 스타일 및 공통 요소 (`auth.css`, `bsq_server.js`)
*   **auth.css:** 인증 관련 페이지 전용 스타일 (입력 폼, 버튼 그라데이션, 모달 등).
*   **bsq_server.js:** 백엔드 서비스(Supabase, Firebase) 초기화 및 공통 서버 설정.

## 🛠 아키텍처 특징
1.  **동적 컴포넌트 관리:** `header.js`를 사용하여 페이지마다 중복되는 헤더, 푸터, 네비게이션 바를 동적으로 주입합니다.
2.  **멀티 백엔드 연동:** Supabase와 Firebase를 동시에 로드하고 있어, 데이터의 성격이나 서비스 요구사항에 따라 두 플랫폼을 혼합하여 사용하는 구조입니다.
3.  **검증 로직:** 클라이언트 사이드에서 아이디 중복 확인 및 정규표현식을 이용한 비밀번호 유효성 검사를 철저히 수행합니다.

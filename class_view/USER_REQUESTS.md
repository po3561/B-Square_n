# B-Square Class View 프로젝트 요구사항 정리

## 1. 핵심 기능 복구 사항
- **관리자 기능**: `view_edit.js` 내 쿠폰 생성 및 관리 탭 기능 복구
- **메시지 렌더링**: 본인 작성 메시지는 우측 정렬 및 `mine` 클래스 정상 처리
- **시스템 버튼**: 다크모드 활성화 토글 버튼 및 보내기 버튼(화살표 스타일) 수정
- **채팅 보조 기능**:
    - 첨부파일 UI 연동 및 데이터 첨부 기능
    - 이모지 입력 피커 및 우클릭 이모지 리액션 확장
    - 답장 기능(프리뷰 팝업) 복구
    - 메시지 수정 및 삭제 기능 (DB 연동)
    - 메시지 검색 기능 (키워드 하이라이트 포함)
    - 고정 메시지 목록 확인 (햄버거 메뉴 클릭 시 슬라이드 오버레이)

## 2. 디자인 및 UX 개선
- **컨셉**: Apple Mac 스타일의 미니멀리즘과 Telegram의 직관적인 UI 결합
- **테마 대비**: 다크모드와 화이트모드의 색감 차이를 뚜렷하게 설정
    - 화이트 모드 시 모든 글자는 검은색 계열로 강제하여 가독성 확보
    - 배경색에 글자가 묻히지 않도록 최적화
- **레이아웃 모션**: 
    - 우상단 정보 패널 오픈 시 채팅 영역이 좁아지며 옆으로 밀려나는 슬라이딩 모션 (Layout Push)
- **스크롤 방식**: 최신 메시지가 아래에 쌓이고 위로 올라가는 표준 채팅 스크롤 방식 적용

## 3. 클래스 모임(Gathering) 고도화 시스템
- **생성 UI**: 첨부파일 아이콘 옆 달력 버튼 렌더링, 드롭다운 및 달력 디자인 정돈
- **생성 규칙**:
    - 모집 기간 설정 기능
    - 모임일 기준 최소 3일 전 생성 제한 (위반 시 안내 문구 출력 및 생성 불가)
- **채팅 연동**: 생성된 모집 카드가 실제 메시지 형태로 채팅창에 업로드
- **실시간 자동화**:
    - 모집 마감까지 남은 시간 실시간 카운트다운 표시
    - 시간 만료 또는 최대 인원 도달 시 자동으로 모집 마감 처리
- **역할별 버튼 로직**:
    - **강사**: [모집 마감] 버튼 노출
    - **일반 수강생**: [클래스 참여 (수강권 1회 사용)], [모임 불참] 버튼 노출
    - **월정액 수강생**: [클래스 참여], [모임 불참] 버튼 노출
- **데이터 관리**: 모든 모임 및 참여 데이터는 데이터베이스(`schema.sql` 기반) 연동 및 조회

## 4. 기타 인프라
- 모든 기능은 D1 API 및 Supabase 연동을 통해 실시간 데이터 처리 보장

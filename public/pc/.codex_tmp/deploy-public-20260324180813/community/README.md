# Community & Real-time Chat (커뮤니티 및 실시간 채팅)

이 폴더는 B-Square 사용자들이 실시간으로 소통할 수 있는 커뮤니티 공간과 채팅 시스템을 포함하고 있습니다.

## 📁 주요 파일 구성
- `community.html`: 커뮤니티의 메인 레이아웃. 좌측 사이드바(채팅 목록)와 우측 메인 채팅창 구조.
- `community.css`: 커뮤니티 전용 스타일시트. 메시지 버블, 참여자 목록, 모바일 대응 레이아웃 등 정의.
- `community.js`: 커뮤니티 모듈들의 실행을 조율하는 메인 컨트롤러. 인증 확인, 클래스 채팅 자동 등록, 이벤트 연결 담당.
- `chat_ui.js`: 채팅창 UI의 모든 동적 로직. 메시지 렌더링, 전송, 이미지/파일 업로드, 메시지 검색, 고정(Pin) 기능 등 포함.
- `chat_list.js`: 참여 중인 채팅방(클래스 채팅, 1:1 DM) 목록 관리 및 실시간 업데이트.
- `sync_bridge.js`: Firebase(실시간 메시지/상태)와 Supabase(사용자 프로필) 간의 데이터 동기화 및 온라인 상태(Presence) 관리.
- `dm_private.js`: 1:1 개인 메시지(DM) 생성 및 초기화 로직.

## 🛠️ 주요 기능
1. **실시간 메시징**: Firebase Realtime Database를 활용하여 지연 없는 실시간 대화를 지원합니다.
2. **클래스 연동**: 수강 중인 클래스에 대한 전용 채팅방이 자동으로 목록에 추가됩니다.
3. **상태 관리 (Presence)**: 사용자의 온라인/오프라인 상태와 마지막 접속 시간을 실시간으로 추적합니다.
4. **고급 채팅 기능**: 답글(Reply), 메시지 고정, 읽지 않은 메시지 카운트, 이미지 전송 등 현대적인 채팅 기능을 제공합니다.
5. **모바일 최적화**: 모바일 환경에서는 사이드바와 채팅창이 전환되는 인터페이스를 제공합니다.

## ⚠️ 주의 사항
- `OPERATOR_GHOST` 아이디를 통해 관리자 모드로 접속 시 로그인 없이도 커뮤니티 모니터링이 가능합니다.
- 메시지 데이터는 Firebase에 저장되지만, 사용자 닉네임과 프로필 이미지는 Supabase에서 가져옵니다.

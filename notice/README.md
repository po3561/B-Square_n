# Notice & FAQ (공지사항 및 자주 묻는 질문)

이 폴더는 B-Square 플랫폼의 공식 공지사항, 클래스별 공지사항 및 FAQ 기능을 관리하는 페이지를 포함하고 있습니다.

## 📁 주요 파일 구성
- `notice.html`: 공지사항 및 FAQ 목록의 메인 구조. 검색바, 카테고리 탭, 목록 그리드 포함.
- `notice.css`: 공지사항 전용 스타일시트. 공지 카드 디자인, 중요 공지 강조 효과, FAQ 아코디언 스타일 등 정의.
- `notice.js`: 사용자용 공지사항 로직. Firebase에서 운영 공지(`notices`)와 클래스 공지(`class_notices`)를 통합 로드하여 표시. 검색 및 필터링 기능 포함.
- `notice_admin.js`: 관리자용 공지사항 작성 및 편집 도구. 운영자 권한 확인 후 공지사항 생성, 수정, 삭제(숨김) 기능 제공.

## 🛠️ 주요 기능
1. **통합 공지 시스템**: 플랫폼 전체 공지사항뿐만 아니라 각 클래스 강사가 작성한 클래스 전용 공지도 한곳에서 확인할 수 있습니다.
2. **실시간 업데이트**: Firebase Realtime Database와 연동되어 새로운 공지가 등록되거나 수정되면 즉시 반영됩니다.
3. **FAQ 아코디언**: 사용자들이 자주 묻는 질문을 카테고리별로 쉽게 찾아볼 수 있도록 아코디언 UI를 제공합니다.
4. **검색 및 필터링**: 제목이나 내용 키워드를 통해 원하는 공지사항을 빠르게 검색할 수 있습니다.

## ⚠️ 주의 사항
- `notice_admin.js`는 운영자 전용 로직을 포함하므로 일반 사용자에게는 노출되지 않도록 권한 체크가 이루어집니다.
- 클래스 공지는 각 클래스의 `class_notices` 노드에서 데이터를 가져옵니다.

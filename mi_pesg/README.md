# My Page (마이페이지)

이 폴더는 사용자의 개인 정보, 수강 중인 클래스 관리, 보안 설정 등을 위한 마이페이지 기능을 포함하고 있습니다.

## 📁 주요 파일 구성
- `mypage.html`: 마이페이지의 메인 레이아웃 및 탭 컨테이너 구조.
- `mypage.css`: 마이페이지 전용 스타일시트. 프로필 카드, 탭 메뉴, 반응형 레이아웃 정의.
- `mypage.js`: 마이페이지의 핵심 오케스트레이터. 인증 상태 확인, 탭 전환 로직, 로그아웃 기능 관리.
- `tab_profile.js`: [프로필] 탭 로직. 사용자 정보(이름, 사진 등) 조회 및 수정 기능.
- `tab_classes.js`: [내 클래스] 탭 로직. 사용자가 구매한 수강권 및 수강 중인 클래스 목록 표시.
- `tab_security.js`: [보안/계정] 탭 로직. 비밀번호 변경, 계정 연동 설정 및 탈퇴 기능 관리.
- `tab_chat_sub.js`: [채팅 설정] 탭 로직. 커뮤니티 채팅 관련 개인 설정 및 알림 관리.

## 🛠️ 주요 기능
1. **통합 사용자 관리**: 사용자의 프로필 정보를 Supabase와 연동하여 실시간으로 업데이트합니다.
2. **수강 내역 추적**: Firebase Realtime Database의 `user_passes` 노드와 연동하여 현재 사용 가능한 수강권을 시각화합니다.
3. **보안 가드**: 로그인이 필요한 페이지로, 인증되지 않은 접근 시 로그인 페이지로 리다이렉트합니다.
4. **모듈형 탭 시스템**: 각 기능별로 스크립트를 분리하여 유지보수성을 높였습니다.

## ⚠️ 주의 사항
- 폴더명 `mi_pesg`는 내부 경로 규칙에 따라 사용되므로 링크 연결 시 주의가 필요합니다.
- 프로필 수정 시 Supabase Auth 및 Database의 동기화가 이루어집니다.

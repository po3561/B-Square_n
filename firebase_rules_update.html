Firebase RTDB 보안 규칙 업데이트

Firebase Console에서 아래 규칙을 적용해주세요:

{
  "rules": {
    "classes": {
      ".read": true,
      "$classId": {
        ".write": "auth != null && (data.child('creator_id').val() === auth.uid || !data.exists())"
      }
    },
    "reviews": {
      ".read": true,
      "$classId": {
        ".write": true
      }
    },
    "chats": {
      ".read": true,
      "$classId": {
        ".write": true
      }
    },
    "enrollments": {
      ".read": true,
      "$userId": {
        ".write": "auth != null && auth.uid === $userId"
      }
    }
  }
}

방법:

  1. Firebase Console → Realtime Database → Rules 클릭
  2. 위 JSON을 복사하여 기존 규칙을 덮어쓰기
  3. Publish 버튼 클릭

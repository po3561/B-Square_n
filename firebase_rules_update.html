⚠️ Firebase RTDB 보안 규칙 업데이트 (필수)

이 프로젝트는 Supabase로 인증하므로, Firebase Auth가 아닌 Supabase 세션으로 권한을 관리합니다.
따라서 Firebase 규칙에서 auth != null 조건을 사용하면 항상 차단됩니다.

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

⚡ 적용 방법:

  1. Firebase Console → Realtime Database → Rules 클릭
  2. 위 JSON을 복사하여 기존 규칙을 전체 교체
  3. Publish 버튼 클릭

※ 주의: 개발 단계에서만 사용하세요. 배포 시 Supabase 기반 서버 인증으로 전환 필요.

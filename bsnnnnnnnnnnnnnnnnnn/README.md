# Core Service (메인 서비스 코어)

이 폴더는 B-Square 서비스의 메인 프런트엔드 페이지와 핵심 공통 UI 구성 요소를 포함하고 있습니다.

## 📁 주요 파일 구성
- `index.html`: 서비스의 메인 랜딩 페이지. 카테고리, 광고 배너, 추천 클래스 등을 표시.
- `main.js`: 메인 페이지 전용 로직. 광고 배너 로딩, 실시간 클래스 목록 렌더링, 카테고리 필터링 및 모바일 Drawer 제어 담당.
- `header.js`: 서비스 전역에서 사용되는 통합 헤더, 푸터, 모바일 사이드 메뉴(Drawer), 하단 네비게이션바 시스템. 모든 페이지에 동적으로 UI를 삽입합니다.
- `recommend_view.html / .js`: 추천 클래스 또는 특정 컬렉션을 상세하게 보여주는 뷰 페이지.
- `style_pc.css`: 데스크톱 환경을 위한 전역 스타일시트.
- `style_mobile.css`: 모바일 환경에 최적화된 전역 스타일시트 (반응형 대응).
- `old_index.html`: 이전 버전의 인덱스 파일 (백업용).

## 🛠️ 주요 기능
1. **통합 UI 시스템**: `header.js`를 통해 모든 페이지에서 일관된 네비게이션 경험을 제공하며, 로그인 상태에 따라 유저 메뉴를 동적으로 변경합니다.
2. **실시간 데이터 바인딩**: Firebase Realtime Database와 연동되어 관리자가 수정한 광고 배너나 사이트 설정이 새로고침 없이(또는 즉시) 반영됩니다.
3. **반응형 디자인**: PC와 모바일용 CSS를 분리하여 각 기기에 최적화된 레이아웃을 제공합니다.
4. **검색 및 필터링**: 메인 페이지에서 클래스 검색 및 카테고리별 필터링 기능을 지원합니다.

## ⚠️ 주의 사항
- `header.js`는 프로젝트의 거의 모든 페이지에서 참조되므로, 수정 시 전체 사이트의 레이아웃에 영향을 미칠 수 있습니다.
- 폴더명 `bsnnnnnnnnnnnnnnnnnn`은 메인 서비스 경로로 사용되므로 링크 연결 시 주의가 필요합니다.
